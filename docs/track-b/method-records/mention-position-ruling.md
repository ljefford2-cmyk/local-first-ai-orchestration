# Track B — Method Record — Mention-Position Ruling (Disclosure Screening)

**Status:** Non-controlling Track B method record. Not part of the controlling architecture and does not supersede Volumes 1–3.
**Date:** 2026-08-22
**Nature of contents:** An owner ruling on disclosure screening, recorded so that later disclosure inspections apply it consistently.

## The ruling

The name or abstract description of a disclosure category, used solely to specify, document, or evaluate a disclosure-control procedure, is not itself a disclosure. It does not protect actual instances, identifying examples, contextually recoverable values, quotations of the screened material, or placeholders copied from the real environment.

## When a mention-position term becomes a disclosure

A term that would otherwise sit in mention position becomes a disclosure under any of these five conditions:

1. It is an actual instance of the category, not the category's name or abstract description.
2. It is a real or partially redacted identifying example.
3. It binds the category to context from which the value is recoverable.
4. It quotes the sensitive string in order to explain its sensitivity.
5. It is a placeholder copied from the real environment rather than genuinely synthetic.

## Scope

The rule is location- and context-scoped, not a global allowlist. Sweeps must continue searching for concrete instances of every named category.

## Timing

This ruling was made after the B1.1–B1.3 passes ran. The escalation that prompted it was correct under the rule as it then stood.
